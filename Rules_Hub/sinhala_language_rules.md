# සිංහල භාෂා සහ Artifacts ඉදිරිපත් කිරීමේ නීති (Sinhala Language Mandate)

## 1. සියලුම Proposals සහ Artifacts සිංහල අකුරින් පමණක් සැපයීම
- පරිශීලකයාට ඉදිරිපත් කරන ඕනෑම **Learning Proposal (learning_proposal.md)**, **Implementation Plan**, **Walkthrough** හෝ වෙනත් ඕනෑම **Artifact** එකක් **100% සිංහල අකුරින් පමණක්** ලිවිය යුතුය.
- කිසිදු හේතුවක් මත ඉංග්‍රීසි භාෂාවෙන් ප්‍රධාන විස්තර හෝ යෝජනා ඉදිරිපත් නොකළ යුතුය (Code syntaxes, file paths, parameters සහ identifiers හැර).

## 2. සන්නිවේදන ශෛලිය (Tone & Script)
- **සාමාන්‍ය කතාබස් බස (Normal Conversational Sinhala)**: පොත් භාෂාවෙන් හෝ අධික විධිමත් (robotic/formal) ආකාරයෙන් කතා නොකර, මිත්‍රශීලීව සාමාන්‍යයෙන් කතා කරන සිංහලෙන් ("කරමු", "බලමු", "තියෙන්නේ", "නැහැ", "හින්දා" වැනි කතා ව්‍යවහාරයෙන්) පිළිතුරු ලබා දිය යුතුය.
- **Artifacts සහ ලේඛන**: සියලුම Artifacts සිංහල අකුරින් සැපයිය යුතු අතර, ඒවායේද කියවීමට පහසු, සරල සහ පැහැදිලි කතා/ලේඛන මිශ්‍ර ස්වභාවික ශෛලියක් පවත්වා ගත යුතුය.
- **තාක්ෂණික පද (Technical Terms)**: කේත, විධාන, පරාමිති හෝ tool නම් ඉංග්‍රීසියෙන්ම යොදමින්, සාමාන්‍ය සිංහලෙන් අදහස පැහැදිලි කළ යුතුය.
