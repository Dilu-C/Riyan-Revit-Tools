# සිංහල භාෂා සහ Artifacts ඉදිරිපත් කිරීමේ නීති (Sinhala Language Mandate)

## 1. සියලුම Proposals සහ Artifacts සිංහල අකුරින් පමණක් සැපයීම
- පරිශීලකයාට ඉදිරිපත් කරන ඕනෑම **Learning Proposal (learning_proposal.md)**, **Implementation Plan**, **Walkthrough** හෝ වෙනත් ඕනෑම **Artifact** එකක් **100% සිංහල අකුරින් පමණක්** ලිවිය යුතුය.
- කිසිදු හේතුවක් මත ඉංග්‍රීසි භාෂාවෙන් ප්‍රධාන විස්තර හෝ යෝජනා ඉදිරිපත් නොකළ යුතුය (Code syntaxes, file paths, parameters සහ identifiers හැර).

## 2. සන්නිවේදන ශෛලිය (Tone & Script)
- කතාබහ, පැහැදිලි කිරීම්, දෝෂ වාර්තා සහ සියලුම පිළිතුරු සුහදශීලී සිංහල බසින් (සිංහල අකුරින්) සැපයිය යුතුය.
- තාක්ෂණික වචන අවශ්‍ය තැන්වලදී ද සිංහල පැහැදිලි කිරීම සමඟ තාක්ෂණික පදය පමණක් වරහන් තුළ දැක්විය හැක.
